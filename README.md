# That Dad Thing LLMS

Machine-readable brand, collection, product, and FAQ files for That Dad Thing.

This repository supports AI search, answer engines, structured discovery, and citation consistency for https://thatdadthing.com.

## Files

- `llms.txt`: high-level brand guide for AI systems
- `ai.txt`: AI access and citation policy
- `manifest.json`: feed directory
- `brand.json`: canonical brand context
- `collections.json`: launch collection context
- `products.json`: starter product feed
- `faq.json`: canonical FAQ content
- `ai-sitemap.xml`: sitemap for the machine-readable files
